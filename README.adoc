= config-key-sanitation

Classify, match, and alert on CLI config keys — active, deprecated, expired, unknown.
Never drop detection of outdated keys.

link:https://docs.opensh.org/open-shell-org/standard-config-key-sanitation.html[Explore the docs »]
endif::[]

== About The Project

CLIs that delete recognition of old config keys create silent mystery debt.
This library loads a machine-readable key catalog, scans key=value config text, and emits structured findings plus human alert lines for **deprecated**, **expired**, and **unknown** keys.

Expired keys stay in the catalog forever and still produce alerts — they are not forgotten.

== Getting Started

=== Prerequisites

LDC or DMD, DUB.

=== Install

Prefer the registry once published:

[source,bash]
----
dub add config-key-sanitation
----

Until the first DUB release, use a path dependency on a sibling clone:

[source,sdl]
----
dependency "config-key-sanitation" path="../config-key-sanitation"
----

=== Demo

[source,bash]
----
dub run --config=demo -- fixtures/sample.npmrc
----

== Usage

[source,d]
----
import config_key_sanitation;
import std.file : readText;

auto catalog = Catalog.loadJson(readText("fixtures/example-catalog.json"));
auto keys = parseKeyValueFile(readText("fixtures/sample.npmrc"));
foreach (f; catalog.classify(keys)) {
    if (f.needsAlert)
        stderr.writeln(f.alertLine);
}
----
